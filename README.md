# Lavish Beauty Salon — Android app

**Download:** [LavishBeautySalon.apk](https://github.com/Zia-Bashir/lavish-beauty-salon-app/releases/latest/download/LavishBeautySalon.apk)

This link always gives the newest version.

## Install
1. Open the link on the Android phone and download the file.
2. Open the downloaded file. If Android asks, allow installing apps from your browser or Files app.
3. Tap **Install**, then open **Lavish Beauty Salon** and sign in with the account your admin gave you.

Requires Android 7.0 or newer. Accounts are created by the salon admin; there is no sign-up.
